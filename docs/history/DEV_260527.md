## floating-ai-button.tsx

### 1. AGI_FALLBACK_URL 미사용 (261번줄)
`AGI_FALLBACK_URL` 상수가 정의만 되고 참조하는 곳이 없음. 제거 필요.
```ts
// 제거 대상
const AGI_FALLBACK_URL = 'http://49.142.52.133:1777'
```

### 2. useState → const 대체 (348번줄)
`agiBaseUrl`은 setter가 없으므로 `useState` 불필요.
```ts
// 현재
const [agiBaseUrl] = useState(AGI_PRIMARY_URL)
// 수정
const agiBaseUrl = AGI_PRIMARY_URL
```

### 3. useCallback deps 누락 (392-414번줄)
`onPointerUp`의 deps 배열이 `[launched]`뿐인데 내부에서 `sendPageContext`를 호출 → stale closure 가능성.
```ts
// 현재
}, [launched])
// 수정
}, [launched, sendPageContext])
```

### 4. 설치 진행률 점프
`setInstallProgress(30)` 후 완료 시 바로 `100`으로 점프. 중간 단계 없어 UX 어색함. (cosmetic)

## app/api/agi/route.ts

환경변수 미설정 시 외부 IP로 조용히 fallback. 의도된 설계지만 env 미설정을 감추는 부작용.
```ts
const SERVER_URL = process.env.JJAPVIS_SERVER_URL ?? 'http://49.142.52.133:1777'
```

### 6. GET 엔드포인트 보안 주의
외부 서버에서 EXE를 받아 `process.cwd()/AGI-client.exe`에 저장 후 `spawn` 실행.
서버(`49.142.52.133`) 탈취 또는 IP 변경 시 임의 코드 실행 위험.
로컬 전용 기능이므로 현재는 허용 가능한 수준이나 주석으로 명시 권장.

## app/api/workspaces/route.ts

### 7. 순차 DB 루프 (233-241번줄)
`order_index` 업데이트를 N번 개별 쿼리로 수행. 현재 워크스페이스 수가 적어 문제없으나 `upsert` 배치로 개선 가능.
```ts
// 현재: for loop N쿼리
// 개선안
await supabaseAdmin.from('workspace_members').upsert(
  uniqueOrderIds.map((id, index) => ({
    workspace_id: id,
    user_id: user.id,
    order_index: index,
  })),
  { onConflict: 'workspace_id,user_id' }
)
```

## 이메일 인증 플로우 개선 (auth-panel.tsx)

### 8. emailRedirectTo 고정 URL로 변경
`window.location.origin` 사용으로 로컬 개발 중 회원가입 시 인증 메일 링크가 `localhost:3000`으로 발송되는 문제 수정.
환경변수 `NEXT_PUBLIC_SITE_URL`을 우선 사용하도록 변경, 폴백은 `https://cowork26dev.vercel.app`.
```ts
// 이전
function getAuthRedirectUrl() {
  if (typeof window !== 'undefined') return window.location.origin
  return process.env.NEXT_PUBLIC_SITE_URL ?? 'https://cowork26.vercel.app'
}
// 이후
function getAuthRedirectUrl() {
  return process.env.NEXT_PUBLIC_SITE_URL ?? 'https://cowork26dev.vercel.app'
}
```

### 9. 이메일 미인증 로그인 처리
`signInWithPassword` 에러에서 `"Email not confirmed"` 케이스를 별도 감지하여 한국어 안내 메시지와 인증 메일 재발송 버튼 표시.

### 10. 회원가입 성공 분기 단순화
`data.session` 유무로 분기하던 로직 제거. Supabase Email Confirmations ON 기준으로 항상 인증 메일 발송 안내 후 로그인 탭으로 전환하도록 통일.

## 페이지 트리 UI 개선 (notion-lite-app.tsx + globals.css)

레퍼런스: `ref/sidebar_design2` — 세로 가이드라인 + 가로 연결선 패턴

### 12. 펼침/접힘 (collapse/expand)
`collapsedPages: Set<string>` state와 `toggleCollapse` callback 추가.
하위 페이지가 있는 항목에만 셰브론(SVG) 표시, 클릭 시 90도 회전 + 하위 트리 토글.
하위 없는 항목은 셰브론 공간을 `opacity-0`으로 유지해 레이아웃 일관성 확보.

### 13. 트리 구조 시각화
인라인 `paddingLeft: depth * 14` 방식 → wrapper 중첩(`ml-5 border-l border-[#4a4a47]`) 방식으로 전환.
- **세로 가이드라인**: 자식 컨테이너의 `border-l`로 부모-자식 연결 표시
- **가로 연결선**: depth > 0 항목에 `absolute -left-px top-1/2 h-px w-3` 배치, active 항목은 `#baf7c8`으로 강조
- **행 좌측 padding**: depth > 0 행에 `pl-3`(12px) 추가로 연결선(-1px~11px)과 셰브론(12px~) 간 겹침 방지

### 14. 액션 버튼 경량화
기존 `36px + border + shadow` 스타일 → `28px` 무테두리 hover-only 스타일로 변경.
트리 항목 밀도 유지하면서 hover 시 부드럽게 표시.

### 15. 페이지 목록 스크롤바 개선
`page-tree-scroll` 클래스 + `globals.css` 추가로 4px 얇은 커스텀 스크롤바 적용.
