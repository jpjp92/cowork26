# DEV_260622 — Markdown 링크 URL Chip 표시

## 요약

Markdown 링크 형식으로 정리된 URL을 에디터 UI에서는 chip 형태로 표시하도록 테스트 프로토타입을 만들고, 실제 Tiptap 에디터에 반영했다. 일반 URL을 그대로 붙여넣거나 입력한 경우에는 원문 URL 텍스트를 유지하고, `[라벨](https://...)` 형식만 chip으로 변환한다.

## 적용 기준

- `https://supabase.com/docs/guides/storage`
  - 그대로 URL 텍스트로 표시
- `[Supabase](https://supabase.com/docs/guides/storage)`
  - 화면에서는 `Supabase` chip으로 표시
  - 저장 데이터에는 Tiptap `link` mark의 `href`로 URL 보존
  - Markdown export 시 `[Supabase](https://supabase.com/docs/guides/storage)` 형태 유지

## 테스트 프로토타입

### 로컬 리뷰 파일

```txt
public/url-chip-review.html
scripts/url-chip-review.mjs
```

두 파일은 구현 전 UI 확인용으로 만들었고, 실제 앱 기능에는 필요하지 않아 `.gitignore`에 추가했다.

프로토타입에서 확인한 항목:

- Markdown 원본 문자열 유지
- Markdown 링크만 chip UI로 렌더링
- bare URL은 chip으로 변환하지 않고 원문 표시
- chip의 `href`에는 원본 URL 유지
- chip vertical alignment 조정

## 실제 앱 변경

### `components/document-editor.tsx`

- `@tiptap/extension-link`를 직접 import하고 의존성에 명시했다.
- `StarterKit.configure({ codeBlock: false, link: false })`로 StarterKit 기본 Link 등록을 끄고, 별도 `ChipLink` extension을 등록했다.
- Link 설정:
  - `autolink: false`
  - `linkOnPaste: false`
  - `openOnClick: true`
  - 기본 class는 `null`
- 붙여넣기 처리:
  - `[label](https://...)` 패턴만 HTML anchor로 변환해 ProseMirror slice로 삽입
  - 삽입되는 anchor에는 `class="url-chip"` 부여
  - 일반 URL은 변환하지 않음
- 직접 입력 처리:
  - custom `InputRule` 추가
  - 사용자가 `[TEST](https://www.naver.com)`을 직접 입력하고 마지막 `)`까지 입력하면 `TEST` chip link로 변환
  - URL은 link mark의 `href`에 보존

### `app/globals.css`

- 일반 링크 스타일 추가
- `.ProseMirror a.url-chip` chip UI 추가
- chip 내부 아이콘은 `::before`로 표시
- 본문 텍스트와 높이를 맞추기 위해 `vertical-align: 0.12em` 적용

### `package.json` / `package-lock.json`

- `@tiptap/extension-link` 직접 의존성 추가

## 검증

```bash
npm run typecheck
npm run build
```

둘 다 통과.

빌드는 로컬 샌드박스에서 Turbopack의 process/port binding 제한으로 실패할 수 있어 승인된 환경에서 재실행해 확인했다.

## 남은 확인 포인트

- 실제 브라우저에서 직접 입력 후 마지막 `)` 입력 시 chip 변환 확인
- 붙여넣기 시 Markdown 링크만 chip 변환되는지 확인
- 기존 저장된 일반 link mark가 있을 경우 class가 없으면 일반 링크 스타일로 표시되는지 확인
- Markdown 다운로드에서 chip link가 기존처럼 `[label](url)`로 export되는지 확인
