# DEV_260526

## 요약

워크스페이스 드롭다운 UI를 네이티브 select에서 커스텀 스위처로 교체하고, 사용자별 워크스페이스 순서 변경을 지원하도록 API와 DB 마이그레이션을 추가했다. 문서 구조도 `plans` 중심으로 재정리했다.

## 앱 변경

- 워크스페이스 선택 UI를 커스텀 드롭다운으로 변경
- 활성 워크스페이스 상태 표시 추가
  - `owner`: `●`
  - `editor`: `◆`
  - `viewer`: `○`
- 활성 워크스페이스 행을 진회색 배경 + 흰색 텍스트로 표시
- role badge 크기와 폰트 크기를 줄여 좁은 드롭다운에서 겹침 방지
- 드롭다운 chevron과 생성 plus를 CSS 도형으로 처리해 중앙 정렬 문제 제거
- 새 워크스페이스 생성 입력을 드롭다운 하단에 배치
- 워크스페이스 행 드래그로 순서 변경 가능
- 순서 변경 실패 시 이전 목록 순서로 롤백

## API / DB 변경

- `workspace_members.order_index` 컬럼 추가
- `GET /api/workspaces`가 membership order 기준으로 워크스페이스를 반환
- `PATCH /api/workspaces`에 `{ orderIds: string[] }` 재정렬 요청 지원 추가
- 새 워크스페이스 생성 시 현재 사용자의 마지막 `order_index + 1`로 membership 생성
