# DEV_260529 — 페이지 마크다운 다운로드 기능 추가

## 요약

사이드바 페이지 행의 hover 액션 영역에 마크다운 다운로드 버튼을 추가했다. TipTap JSON 형식으로 저장된 페이지 content를 클라이언트 사이드에서 Markdown 문자열로 변환해 파일로 내려받는 기능이다.

## 추가된 파일

### `lib/tiptap-to-markdown.ts`

TipTap(ProseMirror) JSON → Markdown 변환 유틸. 외부 패키지 없이 현재 에디터에서 사용하는 노드 타입만 커버한다.

지원 노드:
- `heading` — `#` ~ `######`
- `paragraph`
- `bulletList` / `orderedList` / `listItem` (중첩 지원)
- `blockquote` — `>`
- `codeBlock` — 언어 태그 포함 펜스 블록
- `mermaidBlock` — ` ```mermaid ` 펜스 블록
- `table` / `tableRow` / `tableHeader` / `tableCell` — 헤더 구분선 자동 삽입
- `horizontalRule` — `---`
- `hardBreak` — `  \n`

지원 마크:
- `bold` → `**text**`
- `italic` → `*text*`
- `strike` → `~~text~~`
- `code` → `` `text` ``
- `link` → `[text](href)`
- `fontSize` — Markdown에서 표현 불가, 무시

파일 상단에 `# 페이지 제목`을 삽입한다.

## 수정된 파일

### `components/notion-lite-app.tsx`

사이드바 페이지 행 hover 액션 영역에 `↓` 버튼 추가.

버튼 배치 순서: `+` (하위 페이지 추가) → `×` (삭제) → `↓` (다운로드)

- `+` / `×`는 기존대로 `canEdit`(owner, editor)일 때만 표시
- `↓`는 viewer 포함 모든 역할에서 표시 (다운로드는 읽기 전용)
- 다운로드 시 `pendingContent`(미저장 로컬 편집)가 있으면 해당 내용을 우선 사용
- 파일명: `${page.title || 'untitled'}.md`

관련 위치:
- `components/notion-lite-app.tsx` — `renderPageList` 내 액션 버튼 영역
- `lib/tiptap-to-markdown.ts` — `tiptapToMarkdown` import
