- `hooks/use-page-data.ts`: 페이지 목록, cache, optimistic mutation, background revalidation

- `lib/notion-lite/api.ts`: 인증 header, 오류 parsing, typed API 호출
- `lib/notion-lite/page-tree.ts`, `page-move.ts`: React와 분리된 순수 페이지 계산

### 보존한 핵심 불변조건

- 생성 중 페이지는 POST 완료 전 본문 PATCH를 보내지 않음
- 이전 페이지의 늦은 저장 완료가 현재 페이지 저장 배지를 변경하지 않음
- 미저장 본문을 background revalidation이 덮어쓰지 않음
- workspace 전환 중 늦게 도착한 페이지 응답은 현재 화면을 변경하지 않음
- 짧은 URL 직접 접속, legacy URL 변환, History state 보존, 오래된 route 응답 무시 유지

### 남은 기술 부채

- 저장·내비게이션 훅은 수동 회귀 검증 비중이 높아 향후 브라우저 E2E 테스트 추가가 유용함
- callback ref로 연결된 page data/persistence/navigation 경계는 순환 import를 피하지만 계약 테스트가 추가되면 더 안전함
- `notion-lite-app.tsx`는 목표 범위 상단보다 12줄 많지만, 추가 추출 시 오히려 작은 wrapper가 늘어나는 수준이라 현재 경계를 유지함
