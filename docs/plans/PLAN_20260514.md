# PLAN_20260514

## 주제

Cowork26 피벗: 협업 스프레드시트에서 Notion-lite 협업 문서 도구로 전환.

## 목표

4~5명이 같은 워크스페이스에서 페이지를 만들고, 자료를 정리하고, 문서를 함께 편집할 수 있는 가벼운 Notion + Confluence 형태의 PoC를 만든다.

## 현재 기준 스택

| 영역 | 계획 |
|------|------|
| App | Next.js, React, TypeScript |
| Editor | Tiptap |
| Style | Tailwind CSS |
| Auth/DB | Supabase Auth, Supabase Postgres |
| Future Realtime | Yjs, Hocuspocus |
| Deploy | Vercel, Railway(Hocuspocus 예정) |

## 아키텍처

```txt
Next.js App
  - 로그인 / 세션 관리
  - 워크스페이스 목록
  - 페이지 트리
  - Tiptap Editor

Supabase
  - Auth
  - workspace/page metadata
  - pages.content JSONB
  - pages.ydoc_state future persistence

Future Hocuspocus
  - Yjs realtime sync
  - document authorization
  - cursor / presence
  - ydoc_state persistence
```

## 핵심 테이블

```txt
workspaces
- id
- name
- created_by
- created_at

workspace_members
- workspace_id
- user_id
- role: owner | editor | viewer
- order_index
- created_at

pages
- id
- workspace_id
- parent_id
- title
- order_index
- content
- ydoc_state
- created_by
- updated_by
- created_at
- updated_at
```

`workspace_members.order_index`는 사용자별 워크스페이스 목록 순서를 저장한다.

## Supabase 실행 순서

Supabase Dashboard SQL Editor에서 아래 마이그레이션을 순서대로 실행한다.

```txt
supabase/migrations/001_init.sql
supabase/migrations/002_notion_lite.sql
supabase/migrations/003_workspace_member_order.sql
```

`001_init.sql`은 초기 스프레드시트 PoC 테이블이다. Notion-lite 앱만 운영한다면 핵심은 `002_notion_lite.sql`과 `003_workspace_member_order.sql`이다.

## UI 방향

- 좌측 고정 사이드바 + 상단 헤더 + 중앙 문서 캔버스
- 중성 배경, 검정 border, mint accent
- 워크스페이스 스위처는 커스텀 드롭다운으로 제공
- 활성 워크스페이스는 진회색 배경과 흰색 텍스트로 표시
- 역할 상태는 아이콘과 compact role badge로 표시
- 페이지 액션은 hover/focus 시 노출
- 설정 메뉴는 멤버 목록, 멤버 추가, 로그아웃을 담당
