# 에디터 지원 마크다운 문법

`components/document-editor.tsx` 기준으로 붙여넣기 및 직접 입력 시 동작하는 문법 정리.

---

## 인라인 서식

| 문법 | 결과 |
| --- | --- |
| `**텍스트**` 또는 `__텍스트__` | **굵게** |
| `*텍스트*` 또는 `_텍스트_` | *기울임* |
| `~~텍스트~~` | ~~취소선~~ |
| `` `코드` `` | 인라인 코드 |

---

## 블록 요소

### 제목

```
# 제목 1
## 제목 2
### 제목 3
```

H1 ~ H6 지원 (StarterKit Heading).

### 인용

```
> 인용문 내용
```

### 구분선

```
---
```

### 목록

```
- 항목 1
- 항목 2
  - 중첩 항목 (Tab으로 들여쓰기)

1. 순서 있는 항목
2. 두 번째 항목
```

- `Tab` / `Shift+Tab` 으로 중첩 깊이 조절 (ListTabKeymap).

---

## 코드 블록

````
```언어명
코드 내용
```
````

- 언어명 생략 가능 (` ``` `만 입력해도 코드 블록 생성).
- 언어 하이라이팅은 lowlight(common 프리셋) 사용.
- **직접 입력**: 줄 맨 앞에 ` ``` ` 또는 `~~~` 입력 후 스페이스/엔터 → 코드 블록 생성. 언어명 붙이기 가능 (` ```js `, `~~~python` 등).
- **붙여넣기**: ` ```언어명\n...\n``` ` 형식 텍스트를 붙여넣으면 코드 블록으로 자동 변환.

---

## Mermaid 다이어그램

````
```mermaid
graph TD
  A --> B
```
````

- 붙여넣기 시 `mermaid` 언어로 감지되면 Mermaid 블록 노드로 변환.
- 블록 우측 상단 **편집** 버튼으로 코드 수정 후 저장.
- 렌더링 실패 시 오류 메시지 표시.

---

## 마크다운 링크 → URL Chip

- **직접 입력**: `[라벨](https://example.com)` 마지막 `)` 입력 시 chip으로 즉시 변환 (InputRule).
- **붙여넣기**: `[라벨](URL)` 패턴 텍스트를 붙여넣어도 chip으로 자동 변환.
- 일반 URL(`https://...`)은 변환하지 않고 텍스트 그대로 유지.
- 라벨은 필수 — `[](URL)` 빈 라벨은 chip으로 변환되지 않음.

## 테이블

```
| 헤더 1 | 헤더 2 |
| --- | --- |
| 셀 1 | 셀 2 |
| 셀 3 | 셀 4 |
```

- **필수**: 헤더 행 바로 아래 구분행(`| --- | --- |`)이 있어야 테이블로 인식.
- 셀 내 인라인 서식(굵게, 기울임, 취소선, 인라인 코드, 링크) 지원.
- 열 너비 드래그 리사이즈 지원.
- 행 높이 드래그 리사이즈 지원 (셀 하단 경계 드래그).

---

## 이미지

- 이미지 파일 직접 붙여넣기 → 자동 업로드.
- 다른 페이지의 이미지 복사 → 에셋 클론 후 삽입.
- 삽입된 이미지에 **Copy** 버튼 제공 (HTML + 마크다운 동시 복사).

---

## 붙여넣기 처리 우선순위

같은 텍스트에 여러 규칙이 겹칠 수 있어 아래 순서로 판별:

1. 이미지 파일 (`image/*`)
2. 다른 페이지에서 복사한 이미지 (`data-cowork26-image`)
3. 마크다운 테이블 (구분행 필수)
4. 마크다운 코드 블록 (` ``` `로 시작)
5. 마크다운 링크 (`[라벨](URL)` 패턴)
6. 기본 Tiptap 붙여넣기

## 지원하지 않는 문법 (주의)

| 문법 | 비고 |
| --- | --- |
| 구분행 없는 파이프 테이블 | KQL 등 파이프 연산자 오파싱 방지로 비활성 |
| 자동 URL 링크 (`autolink`) | 비활성 — 일반 URL은 텍스트로 유지 |
| 붙여넣기 자동 링크 변환 (`linkOnPaste`) | 비활성 |
